Automatically compares the same portfolio rule across calendar years, MOM lookbacks and rebalance periods. This is for robustness testing — not automatic parameter optimization.
A. Cross-Year Strategy Robustness — primary view
Each row is one fixed strategy. Read across the years to see whether it works consistently or only in one lucky period.
How to read this: prefer broad consistency over one spectacular cell. A strategy with more positive years, a tolerable worst year, reasonable full-period Sharpe and acceptable drawdown is more credible than a strategy that wins one year and fails nearby years/parameters.
B. MOM × Rebalance Sensitivity — secondary view
Use this heatmap to check whether neighboring parameter combinations behave similarly. An isolated green cell surrounded by red is a warning sign for overfitting.
